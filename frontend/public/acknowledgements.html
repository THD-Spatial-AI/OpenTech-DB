Acknowledgements

Last updated: August 2026

We would like to extend our gratitude to the developers and contributors of the following tools, frameworks, and data sources that make OpenTech-DB possible. Thank you for your continuous innovation and commitment to open science.

Frontend

React 19Open-source JavaScript library for building user interfaces, maintained by Meta and a community of developers. Uses the new use() hook and concurrent rendering features.
TypeScriptStrongly typed superset of JavaScript providing compile-time safety and improved developer tooling across the entire codebase.
ViteNext-generation frontend build tool providing fast hot module replacement and optimised production bundles.
TailwindCSSUtility-first CSS framework used for the entire design system including custom colour tokens aligned with Material Design 3.
Radix UIAccessible, unstyled component primitives providing the foundation for dialogs, tooltips, and other interactive UI components.
Material SymbolsGoogle's open-source variable icon font used throughout the interface for consistent iconography.
ZustandLightweight state management library used for UI state stores across the application.
LeafletOpen-source mapping library powering the Technology World Map view for interactive geographic visualisation of deployment data.
Apache EChartsComprehensive charting and visualisation library used for technology parameter charts, time series profiles, and cost comparisons.

Backend & Infrastructure

FastAPIHigh-performance Python web framework providing the REST API with automatic OpenAPI documentation and Pydantic v2 validation.
Pydantic v2Data validation and settings management library serving as the single source of truth for all technology parameter schemas.
PostgreSQLPowerful open-source relational database system used for scraper candidates, runs, and contributor account data.
SupabaseOpen-source Firebase alternative providing authentication (GoTrue) and database tooling. Self-hosted on DIT infrastructure — no data leaves the university.
APSchedulerPython task scheduling library running the automated data collection pipeline on the 1st and 15th of each month.
CaddyAutomatic HTTPS reverse proxy handling SSL termination, URL routing, and clean URL rewrites for the platform.
DockerContainer platform used for consistent deployment and orchestration of all platform services.

Data Sources

NREL ATBNational Renewable Energy Laboratory Annual Technology Baseline — a primary source of cost and performance projections for energy technologies in the United States.
IRENAInternational Renewable Energy Agency — providing global renewable energy cost and capacity data used in the catalogue.
IEAInternational Energy Agency — providing technology cost benchmarks and energy statistics referenced by catalogue parameters.
OpenAlexOpen-access scientific literature index used by the automated scraper pipeline to discover and extract parameters from peer-reviewed papers.
Semantic ScholarAI-powered literature search engine used by the scraper to identify relevant energy technology publications.
CrossrefScholarly metadata service used by the scraper pipeline to resolve DOIs and retrieve publication provenance for parameter sources.
Open Energy OntologyA shared ontology for the energy domain developed by the open_eGo project, used as the conceptual framework for aligning technology definitions and parameter semantics in this database.

Framework Adapters

PyPSAPython for Power System Analysis — open-source tool for simulating and optimising power systems. OpenTech-DB exports parameters directly to PyPSA-compatible format.
CalliopeVersatile energy system modelling framework. OpenTech-DB supports exports for both Calliope 0.6 and 0.7 with appropriate name and unit mappings.
OSeMOSYSOpen Source energy Modelling SYStem — a linear programming framework for long-term energy planning. OpenTech-DB provides OSeMOSYS-compatible parameter exports.
AdOpT-NET0Energy system optimisation framework developed by the Utrecht University Energy & Resources group. OpenTech-DB supports AdOpT-NET0 template export format.

OpenTech-DB is developed at THD Spatial AI, Deggendorf Institute of Technology. Source code: github.com/THD-Spatial-AI/OpenTech-DB
